# Security Policy

## Supported version

The currently maintained version on the protected default branch is supported.

## Reporting a vulnerability

Please **do not** open a public issue for a suspected security vulnerability.

Use GitHub's private vulnerability reporting feature from this repository's **Security** tab when it is available. If private reporting is unavailable, contact the repository owner privately through GitHub and include only the minimum information needed to establish contact.

## What to include

Provide a concise description of the issue, the affected area, safe reproduction steps, and any suggested mitigation. Do not include passwords, API keys, customer data, payment data, or other secrets in a report.

## Response goal

The repository owner aims to acknowledge a valid report within five business days, assess impact, and coordinate a fix before public disclosure.
